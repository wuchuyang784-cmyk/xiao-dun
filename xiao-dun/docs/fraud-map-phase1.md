# 诈骗案例地图第一阶段

## 当前已落地

- 中央空白区域替换为 ECharts 中国省级地图容器。
- 省级案件数量和高风险数量形成热力值。
- 新增案例通过现有 SSE 事件总线触发 `effectScatter` 脉冲。
- 左侧面板展示案例列表，右侧面板展示风险统计和省份排行。
- 页面初次加载获取完整快照，之后每 1 小时重新校准一次。
- 新增案件接口：`POST /api/v1/fraud-cases`。
- 地图统计接口：`GET /api/v1/fraud-statistics/provinces`。
- 地图案例接口：`GET /api/v1/fraud-cases`。

## 当前数据状态

后端暂时使用 `src/services/fraud-case-service.js` 中的内存演示数据，重启服务后会恢复演示数据。下一阶段接入 SQLite/正式数据导入时，只需要替换服务层，不需要重写地图组件。

## 需要项目方提供

1. 正式中国省级 GeoJSON 文件及其授权/来源说明。
2. 诈骗案例真实字段映射：案例编号、省份编码、经纬度、诈骗类型、风险等级、损失金额、案件状态、发生时间。
3. 数据进入方式：人工导入、App 检测、批量接口或数据库同步。
4. 风险等级枚举和统计口径，例如“高风险”是否包含“严重风险”。
5. 哪些字段允许在管理后台直接展示。
