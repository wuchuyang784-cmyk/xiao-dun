# 小盾诈骗风险研判：报案模板设计（待审核）

已接入风险研判：仅在用户明确确认已造成实际损失时，系统会依据已知事实生成草稿；未知内容保持“待补充”。系统不会自动提交报案，也不会自动向外部平台推送。

## 设计原则

- 先给结论和止损动作，再给案情细节。
- 只整理用户明确提供的事实，不替用户补写未知信息。
- 金额、账号、电话号码、链接保留原始格式，便于复制和核对。
- 微信版使用纯文本和短段落，不使用 Markdown 表格。

## 报案模板

【疑似诈骗案件情况说明】

一、基本案情  
1. 报案人：  
2. 联系方式：  
3. 发生地点：  
4. 发现时间：  
5. 诈骗类型：  

二、诈骗时间线  
1. `YYYY-MM-DD HH:mm`：对方通过【微信/电话/短信/平台】联系。  
2. `YYYY-MM-DD HH:mm`：对方以【身份/理由】要求【点击链接/扫码/下载 App/转账】。  
3. `YYYY-MM-DD HH:mm`：本人完成或拒绝了【具体操作】。  
4. `YYYY-MM-DD HH:mm`：发现异常并采取【联系银行/报警/冻结】措施。  

三、对方信息  
- 自称身份：  
- 微信号/昵称：  
- 电话号码：  
- 收款账户/银行卡号：  
- 链接或二维码内容：  
- 使用的平台或 App：  

四、涉案金额与支付渠道  
- 涉案金额：人民币【】元  
- 支付时间：  
- 支付方式：【银行卡/微信/支付宝/数字钱包/其他】  
- 收款账户：  
- 是否仍可追回或撤回：  

五、证据清单  
1. 原始聊天记录和截图  
2. 电话号码、微信号、群聊或平台账号  
3. 链接、二维码截图和页面记录  
4. 转账凭证、订单号、流水号  
5. 下载的 App、文件、邮件或短信  
6. 与银行、平台、96110、110 的沟通记录  

六、已采取措施  
- 是否联系银行止付/冻结：  
- 是否联系平台申诉：  
- 是否拨打 96110：  
- 是否报警及受理情况：  
- 是否更改密码、解绑银行卡或关闭权限：  

七、待补充信息  
- 精确发生时间：  
- 对方完整账号、电话或链接：  
- 收款账户开户行：  
- 交易流水号/订单号：  
- 实际损失金额：  
- 其他证人或设备信息：
